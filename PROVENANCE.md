# Public Provenance and Release Boundary

This repository is the public website/deployment surface for **Universal Balance Theory (UBT)** at `universalbalancetheory.ca`.

## Source role

- This repository owns public website and deployment truth for the site.
- It does not replace scientific canon, experiment-specific frozen frames, Record-P receipts, private research archives, Luna Bank, or other repositories that own different source roles.
- A public webpage, commit, branch, issue, pull request, image, or draft file does not become scientific authority merely by existing here.

## Public identity

The site identifies Universal Balance Theory as the work of Michael Eric West and uses the exact brand **Luna•Prime•Protocol** where that collaboration/governance layer is referenced.

This provenance file records repository and release boundaries. It does not create, transfer, waive, or reinterpret legal ownership, copyright, trademark, patent, licensing, or other intellectual-property rights.

## Public-release boundary

Only material intentionally approved for public release belongs in this repository.

Do not publish through this repository:

- secrets, credentials, recovery codes, private keys, access tokens, or unpublished service configuration
- private Drive links, private chat exports, unpublished Luna Bank material, or internal continuity records
- medical, financial, or other private personal records
- third-party material without a clear public-release or reuse basis
- private contributor correspondence or attachments unless separately cleared for public release

## Third-party non-absorption

Outside contributions, community Trigon runs, independent frameworks, datasets, and collaborators retain their own provenance and identity. Public integration must preserve authorship, attribution, independence, consent/reuse boundaries, and any applicable claim ceiling.

Community Trigon runs must remain distinguishable from UBT / Luna•Prime•Protocol project-originated R&D so internal work is not presented as independent validation and outside work is not silently absorbed into internal authorship.

## Evidence and claim discipline

Public records must preserve the actual result state, including uncertainty, nulls, failures, ambiguity, blocked work, and superseded states.

A repository change, successful deployment, code execution, visual match, mathematical identity, or workflow completion is not by itself empirical confirmation of UBT.

## Change-control expectation

Prefer small, reviewable, reversible changes.

For public-facing or provenance-sensitive changes:

1. start from current `main`;
2. use an isolated branch;
3. review the final diff;
4. verify that no private data or secrets were introduced;
5. preserve contributor/source provenance;
6. merge only after the public-release boundary is satisfied;
7. document material corrections additively rather than silently rewriting history.

See also `SECURITY.md` and `.github/pull_request_template.md`.
